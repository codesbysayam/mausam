Atmospheric Intelligence REST API

Comprehensive WMO-No. 8 & IMD GTS compliant data interchange endpoints with C-accelerated psychrometrics and Python ETL pipeline integration.

Authentication & Rate Limits

During the current development and public evaluation tier, meteorological endpoints are accessible via standard HTTPS headers. Future production pipelines enforce HMAC authentication and WMO GTS subscriber tokens.

Standard Request Headers:
Accept: application/json X-Mausam-Client: Web-Dashboard/v2.4 X-Data-Precision: WMO-Standard
Rate Limiting Policy:

Unauthenticated requests are rate-limited to 120 requests/minute per IP. Rate limit status is transmitted via standard response headers:

X-RateLimit-Limit: 120 X-RateLimit-Remaining: 118 X-RateLimit-Reset: 1725876000

Multi-Tier Computational Architecture

MAUSAM does not dump unverified external APIs. All observations flow through the C Numerical Core (Welford statistics, IDW spatial interpolation, Stull psychrometrics), validated against Indian climatological extremes, and served via typed Express API endpoints.

[IMD AWS / GTS + Open-Meteo + CPCB CAAQMS] │ ▼ [Python Ingestion & Models] │ ▼ [C Numerical Core (libmausam_numerical.so)] - Stull Tw (°C) & Steadman HI (°C) - Welford Running Variance & Outlier Detection - 2D Spatial IDW Grid Interpolation │ ▼ [Express API / React Application Layer]
GET /api/weather/observations

Retrieves high-precision meteorological observations from automatic weather stations, normalized across IMD and Open-Meteo sources with derived thermodynamic parameters.

Query Parameters:
  • station_id (string, optional) - WMO 5-digit index (e.g. 42182)
  • latitude & longitude (float) - Center coordinates for nearest-station search
Sample JSON Response:
{ "status": "success", "data": { "station_id": "42182", "name": "New Delhi (Safdarjung)", "timestamp": "2026-09-09T07:00:00Z", "temperature_c": 34.2, "dew_point_c": 25.8, "wet_bulb_c": 27.9, "heat_index_c": 44.5, "relative_humidity": 62, "pressure_hpa": 1004.8, "wind_speed_kmh": 14.8, "wind_direction_deg": 110, "qc_status": "VERIFIED_ACCURATE" } }
GET /api/stations

Returns the active registry of IMD and state automatic meteorological stations, complete with geographical coordinates, elevation, Doppler radar coverage status, and sensor operational integrity.

Query Parameters:
  • state (string, optional) - Filter by Indian State / UT (e.g. Odisha, Delhi)
  • type (string, optional) - Station class: AWS, ARG, AERODROME, RADAR
Sample JSON Response:
{ "status": "success", "count": 2, "data": [ { "id": "42971", "wmo_index": "42971", "name": "Bhubaneswar Observatory", "district": "Khordha", "state": "Odisha", "latitude": 20.2444, "longitude": 85.8178, "elevation_m": 45, "radar_station": "Paradip S-Band DWR", "status": "OPERATIONAL" }, { "id": "42182", "wmo_index": "42182", "name": "New Delhi (Safdarjung)", "district": "New Delhi", "state": "Delhi", "latitude": 28.5847, "longitude": 77.2066, "elevation_m": 216, "radar_station": "Mausam Bhavan Palam C-Band", "status": "OPERATIONAL" } ] }
GET /api/weather/forecast

Returns multi-model NWP forecast time series (ECMWF IFS, GFS, NCMRWF Unified Model, and WRF-ARW) including rainfall accumulation probabilities, diurnal temperature curves, and synoptic convective spread.

Query Parameters:
  • stationId or id (string) - WMO station code (e.g. 42971)
  • days (integer, optional, default: 7) - Forecast horizon (1 to 10 days)
Sample JSON Response:
{ "status": "success", "stationId": "42971", "location": "Bhubaneswar, Odisha", "issued_utc": "2026-09-09T06:00:00Z", "daily": [ { "date": "2026-09-09", "temp_max_c": 33.5, "temp_min_c": 25.4, "condition": "Thundershowers likely", "precipitation_mm": 28.4, "rain_probability": 85, "models": { "ecmwf": { "temp_max": 33.2, "rain_mm": 31.0 }, "gfs": { "temp_max": 34.0, "rain_mm": 25.2 }, "ncmrwf": { "temp_max": 33.4, "rain_mm": 29.1 } } } ] }
POST /api/weather/verify

Runs C-accelerated WMO verification metrics on user-provided arrays of forecasts and observations.

// Request Payload { "forecasts": [34.5, 30.1, 31.8], "observations": [34.2, 29.8, 31.5] } // Response { "status": "success", "metrics": { "sample_size": 3, "mae": 0.3, "rmse": 0.3, "mean_bias": 0.3, "pearson_r": 0.999 } }
GET /api/air-quality

Streams Central Pollution Control Board (CPCB) continuous ambient air quality monitoring station (CAAQMS) telemetry, parsed through Indian National Air Quality Index (NAQI) break-point equations.

Sample JSON Response:
{ "status": "success", "city": "Bhubaneswar", "station": "Patia CAAQMS", "aqi": 72, "category": "Satisfactory", "prominent_pollutant": "PM2.5", "pollutants": { "pm25": { "value": 44.2, "unit": "µg/m³", "sub_index": 72 }, "pm10": { "value": 68.1, "unit": "µg/m³", "sub_index": 68 }, "no2": { "value": 18.4, "unit": "µg/m³", "sub_index": 23 }, "so2": { "value": 9.2, "unit": "µg/m³", "sub_index": 12 }, "co": { "value": 0.6, "unit": "mg/m³", "sub_index": 30 }, "o3": { "value": 24.0, "unit": "µg/m³", "sub_index": 24 } }, "health_advisory": "Minor breathing discomfort to sensitive people." }
GET /api/warnings

Disseminates standardized meteorological warnings aligned with National Disaster Management Authority (NDMA) Common Alerting Protocol (CAP) standards and IMD 4-tier color coding.

Sample JSON Response:
